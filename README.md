# Сайт «Восточка»

Сайт-меню с корзиной. Клиент выбирает блюда, указывает адрес и телефон, нажимает
«Отправить заказ в WhatsApp» — и заказ приходит вам в WhatsApp готовым сообщением.
Оплата — переводом на Kaspi после подтверждения.

## Файлы

| Файл | Что внутри |
|---|---|
| `config.js` | **Номер WhatsApp, Kaspi, адрес, часы работы** — заполните в первую очередь |
| `menu.js` | Меню, цены, комбо, сеты и конструктор «Накрыть стол» (`EVENT_MENU`: какие блюда, единицы — порц./шт./кг, нормы на гостя для кнопки «Подобрать меню»; `EVENT_SERVICES`: услуги) |
| `index.html`, `styles.css`, `app.js` | Сам сайт (трогать не нужно) |
| `img/` | Фото блюд (сейчас вырезаны из печатного меню) |

## Что заполнить перед запуском (`config.js`)

1. `whatsapp` — номер WhatsApp для заказов, только цифры: `'77011234567'`
2. `phone` — телефон для звонков: `'+7 701 123 45 67'`
3. `kaspiPhone` и `kaspiName` — куда переводить и имя получателя
4. `kaspiQr` — если есть картинка Kaspi QR, положите её в `img/` и впишите путь
5. `hours` — часы работы, `instagram`, `twoGisLink`

## Как поменять цену

Откройте `menu.js`, найдите блюдо и поменяйте число после `price:`.
Цены сетов пересчитываются сами (сумма блюд минус скидка `discount`).

После любых правок поменяйте в `index.html` цифру `?v=3` на `?v=4` (и т.д.),
чтобы у клиентов обновился сайт, а не показывалась старая версия.

## Как бесплатно выложить в интернет

Самый простой способ — **Netlify Drop**: откройте app.netlify.com/drop,
зарегистрируйтесь и перетащите туда папку `восточка` целиком. Через минуту будет ссылка
вида `vostochka.netlify.app`. Позже можно купить свой домен (например `vostochka.kz`).

Ссылку на сайт поставьте в Instagram, 2GIS, статус WhatsApp и QR-код на упаковку.

## Как посмотреть на компьютере

Откройте `index.html` двойным кликом — сайт откроется в браузере.
